# Autonomous Execution & Non-Interactive Behavior

- **Do Not Ask Questions:** Never prompt the user for clarification, confirmation, or choices. Do not invoke `ask_question`.
- **Autonomous Decision Making:** When encountering ambiguity, multiple options, or architectural trade-offs, automatically select the most sensible, modern, and robust default without asking.
- **Proceed End-to-End:** Execute all required steps, tool calls, and modifications proactively to complete the user's objective from start to finish.
- **State Assumptions & Actions:** Summarize key decisions, assumptions, and actions taken in the final response after completing the work.
