# Gravity SEO Agency - AI WordPress Theme

**Gravity SEO Agency** is an ultra-modern, high-conversion WordPress theme crafted specifically for SEO agencies, AI startups, search engineering consultancies, and digital growth firms.

Packed with modern AI aesthetic styling, kinetic typography (Google Fonts **Outfit** & **Plus Jakarta Sans**), interactive cursor-spotlight Bento cards, live SEO audit scanner simulation, animated counters, infinite logo marquees, and dynamic dark mode ambient glow.

---

## Kinetic Motion & AI Animation Features

- 🌟 **Cursor Spotlight Bento Grid:** As visitors hover and move over service and pricing cards, a radial light beam tracks their exact mouse position (Linear & Vercel style).
- 🔍 **Interactive Live SEO URL Scanner:** Visitors enter their domain into the hero bar to trigger an animated progress bar and terminal audit telemetry simulation.
- 🔢 **Scroll-Triggered Number Counters:** Animates metrics (`+340%`, `99.4%`, `14.8M`, `24/7`) into place with smooth cubic easing as they scroll into viewport.
- ♾️ **Infinite Brand Logo Marquee:** Continuous horizontal ticker showcasing client trust badges with pause-on-hover.
- 🪄 **Scroll Reveal Pipeline:** Staggered fade-up animations on headings, pills, and cards using high-performance `IntersectionObserver`.
- ⚡ **Pulsing Status Beacon:** Live pulsing radar indicator showcasing "AI Search Crawlers: Operational 99.98%".
- 🎯 **Interactive FAQ Accordion:** Smooth CSS height transitions with rotating chevrons.

## Installation Guide

### Method 1: WordPress Admin Upload (Recommended)
1. In your WordPress admin, go to **Appearance > Themes**.
2. Click **Add New Theme**, then **Upload Theme**.
3. Choose the generated `gravity-seo-agency.zip` file.
4. Click **Install Now** and then **Activate**.
5. Go to **Settings > Reading** and choose **Your latest posts** (or select a static front page using the front-page template).

### Method 2: Manual Directory Copy
Copy the `gravity-seo-agency` directory to your WordPress installation:
```
wp-content/themes/gravity-seo-agency
```
Then activate **Gravity SEO Agency** under **Appearance > Themes**.
